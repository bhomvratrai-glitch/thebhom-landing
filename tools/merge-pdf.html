How to merge PDF files into one document

Merging works best when you decide the final order first and use clearly named source files. ToolNest's browser-side merger combines the selected PDFs into a new PDF.

Prepare your files

Rename files in the desired order before selecting them. Check that you are using the latest copies.

Merge

Open the PDF tab, select Merge PDF, add the files and run the merge. The output is a new PDF file.

Check the final document

Open the generated file and confirm page order, page count and readability before sharing it.
