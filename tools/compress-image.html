How to compress an image without making it unusably blurry

Image compression is a balance between dimensions, file format and quality. For web use, reducing unnecessary dimensions often saves more than endlessly lowering quality.

1. Start with the correct dimensions

An image intended to appear at 1200 pixels wide rarely needs to be exported at 5000 pixels wide. Resize first when the source is much larger than the final use.

2. Pick a useful format

WebP is a practical default for many websites. JPG works well for photographs; PNG is useful when transparency or crisp graphic edges matter.

3. Compare the result

Look at both file size and visible quality. A smaller file is not automatically better when it creates obvious artifacts.
