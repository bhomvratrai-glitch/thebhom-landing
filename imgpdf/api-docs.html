API Documentation

REST API for programmatic image and PDF processing. All endpoints accept multipart/form-data.

Base URL: https://imgpdf.thebhom.in
POST/api/v1/image/compress

Compress an image (JPG, PNG, WEBP)

Params: file (binary), quality (low|balanced|max)

POST/api/v1/image/resize

Resize an image

Params: file (binary), width (int), height (int), fit (inside|fill)

POST/api/v1/image/rotate

Rotate/flip an image

Params: file (binary), angle (90|180|270), flipH (bool), flipV (bool)

POST/api/v1/image/crop

Crop an image

Params: file (binary), left (int), top (int), width (int), height (int)

POST/api/v1/image/convert

Convert image format

Params: file (binary), format (jpg|png|webp|tiff), quality (int)

POST/api/v1/image/watermark

Add text watermark

Params: file (binary), text (string), opacity (int)

POST/api/v1/pdf/merge

Merge multiple PDFs

Params: files (multiple binary)

POST/api/v1/pdf/split

Split PDF by pages

Params: file (binary), pages (string: "1-3,5" or "every:2")

POST/api/v1/pdf/compress

Compress PDF

Params: file (binary), level (extreme|recommended|low)

POST/api/v1/pdf/rotate

Rotate PDF pages

Params: file (binary), angle (90|180|270)

POST/api/v1/pdf/remove-pages

Remove pages from PDF

Params: file (binary), pages (string: "2,5,8-10")

POST/api/v1/pdf/extract-pages

Extract pages to new PDF

Params: file (binary), pages (string: "1,3-5")

POST/api/v1/pdf/watermark

Add watermark to PDF

Params: file (binary), text, opacity, rotation

POST/api/v1/pdf/page-numbers

Add page numbers

Params: file (binary), position, startNum

POST/api/v1/pdf/sign

Add typed signature

Params: file (binary), text, method (type)

POST/api/v1/pdf/jpg-to-pdf

Convert images to PDF

Params: files (multiple binary images)

Example: Compress Image

curl -X POST https://imgpdf.thebhom.in/api/v1/image/compress \
  -F "file=@photo.jpg" \
  -F "quality=balanced" \
  -o compressed.jpg
